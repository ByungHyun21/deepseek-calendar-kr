# deepseek-calendar-kr (dsh-calendar)

[DeepSeek Harness](https://github.com/deepseek-ai) 웹 UI 사이드바 하단에 뜨는 **한국어 달력 · 일정 위젯** 플러그인입니다.

사이드바 좌측 하단(설정 · "더 보기" 줄 바로 위)에 폭을 맞춘 월력이 붙고, 날짜를 눌러 그 날의 일정을 확인·추가합니다. 한국 공휴일과 대체공휴일이 계산되어 빨간색으로 표시됩니다.

<img src="docs/screenshot.png" width="260" alt="다크 테마로 표시된 2026년 11월 달력 위젯. 일요일은 빨강, 토요일은 파랑, 오늘 날짜가 선택되어 있고 아래에 선택 날짜 일정 목록과 + 일정 추가 버튼이 있습니다">

## 기능

- **월력 위젯** — 사이드바 하단에 자동 배치, 폭은 사이드바에 맞춤. 창 크기·사이드바 폭이 바뀌면 따라갑니다
- **일정 관리** — 추가 · 수정 · 삭제. 제목, 시작일, 종료일(비우면 하루), 시작 시간
- **기간 일정** — 시작일~종료일 전체가 달력에 표시되고, 시작일에는 일정 개수 막대, 가운데 날짜는 옅은 밴드로 칠해집니다
- **선택 날짜 일정 목록** — 달력 아래에 최대 3개 표시, 넘치면 스크롤. 행을 누르면 수정, ✕ 로 삭제
- **일정 개수 표시** — 배경 틴트(1·2·3개 이상으로 짙어짐) + 아래 분할 막대(4개 이상이면 마지막 막대가 흐려짐)
- **공휴일** — 양력 기념일 + 음력 명절(설날 · 추석 · 부처님 오신 날) + **대체공휴일 규칙 계산**. 공휴일은 일요일과 같은 빨간 굵은 글자, 이름은 선택 날짜 머리글과 툴팁에 표시됩니다
- **요일 색상** — 일요일 빨강, 토요일 파랑
- **다크 테마** — `body[data-ds-dark-theme]`에 맞춰 별도 팔레트
- **모바일 숨김** — 터치 화면·좁은 화면에서는 위젯을 보여주지 않습니다. [설정](#설정)의 `hideOnMobile`에서 끌 수 있습니다 (기본: 켬)
- **저장** — 브라우저 `localStorage`, 탭 간 실시간 동기화. 서버·네트워크 불필요

## 설정

플러그인 관리자 → **달력 · 일정** 행을 열면 `hideOnMobile` 토글이 있습니다. 끄면 모바일에서도 예전처럼 달력이 붙습니다.

| 설정 | 기본값 | 동작 |
|---|---|---|
| `hideOnMobile` | `true` | 모바일에서 달력 위젯을 숨긴다. `false`면 모든 화면에서 보인다 |

모바일 판정 규칙 (`client.js`의 `모바일 판정` 주석에 같은 내용이 있습니다):

1. 주 입력이 터치 — `(hover: none) and (pointer: coarse)`. 태블릿 가로 모드처럼 화면이 넓어도 숨깁니다. 위젯이 `position: fixed` 오버레이라 본문을 덮기 때문입니다.
2. 터치를 지원하는 기기에서 뷰포트 폭이 768px 미만 — 데스크톱 사이트를 요청한 태블릿처럼 1번에 걸리지 않는 기기를 잡습니다.

**데스크톱에서 창만 좁힌 경우는 숨기지 않습니다.** 터치 입력이 없는 기기는 2번에 걸리지 않도록 두었는데, 좁힌 창은 사용자가 잠깐 만드는 상태이고 그 상태에서도 사이드바 발판이 살아 있어 위젯이 제자리를 지키기 때문이며, 무엇보다 데스크톱 동작을 바꾸지 않는 것이 이 플러그인의 전제이기 때문입니다. 터치 지원 노트북·컨버터블은 창을 좁히면 2번에 걸려 숨겨집니다.

가려지는 것은 화면뿐입니다. 일정은 `localStorage`에 그대로 남아 있고, 다른 탭·다른 기기(같은 브라우저)에서도 그대로 보이며, 넓은 화면으로 돌아가면 달력이 바로 돌아옵니다.

설정 값은 Host 반쪽(`plugin/host.js`)의 `Config`가 저장하고, 브라우저는 설정 미러(`ctx.configForms`)로 읽어옵니다. 설정 카드를 붙이지 못하는 배포(설정 화면·슬롯이 없는 경우)에서는 기본값 `true`로 동작합니다.

설정에 보이는 한/영 문구는 `locale/*.json`의 `config` 항목에 정해 두고, 브라우저의 설정 카드에는 같은 글자를 그대로 적어 두었습니다(브라우저는 패키지 안의 JSON을 직접 읽지 못합니다). 한쪽을 고르면 다른 쪽도 함께 고치세요.

### 수동 확인

1. 폰(또는 개발자 도구 → 디바이스 툴바)에서 좁은 화면으로 열면 → 사이드바 하단에 달력이 붙지 않는다. 넓은 화면으로 되돌리면 다시 붙는다.
2. 플러그인 관리자 → 달력 · 일정 → `hideOnMobile` 끄기 → 좁은 화면에서도 달력이 보인다. 켜면 다시 숨겨진다.
3. 숨긴 상태에서도 일정은 사라지지 않는다: `localStorage`의 `dsh-calendar:*` 값이 그대로 있고, 넓은 화면에서 달력을 다시 열면 방금 전까지 보던 달·선택 날짜 그대로 복원된다.
4. 데스크톱(마우스 전용)에서 창을 최대한 좁혀도 달력이 그대로 보인다 (의도한 동작).

## 설치

DeepSeek Harness를 실행한 상태에서, 에이전트에게 아래처럼 시키거나 설정 → 플러그인에서 직접 설치합니다.

> `git@github.com:ByungHyun21/deepseek-calendar-kr.git` 를 클론해서 `install_bundle` 으로 설치해 줘

플러그인 관리자 도구로 직접 설치한다면:

```
plugin_manager  action=install_bundle  target=<클론한 폴더 경로>
```

설치 후 **페이지를 새로고침**하면 위젯이 나타납니다 (클라이언트 코드는 페이지 부트 시 로드됩니다).

## 제거

설정 → 플러그인에서 토글하거나:

```
plugin_manager  action=remove_bundle  target=dsh-calendar
```

일정 데이터는 브라우저 `localStorage`의 `dsh-calendar:*` 키에 남으므로, 남기고 싶지 않으면 개발자 도구에서 지우면 됩니다.

## 공휴일 계산 규칙

「관공서의 공휴일에 관한 규정」 기준으로 계산합니다.

| 종류 | 항목 |
|---|---|
| 양력 고정 | 신정, 3·1절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절 / 2026년부터 노동절·제헌절 |
| 음력 | 설날 연휴(전날~다음날), 추석 연휴(전날~다음날), 부처님 오신 날 |
| 대체공휴일 | 명절 연휴가 일요일·다른 공휴일과 겹치거나, 대체 적용 공휴일이 토요일·일요일·다른 공휴일과 겹치면 **그 다음 첫 비공휴일**. 신정·현충일은 미적용 |
| 선거일 | `ELECTION_DAYS` 표에 등록된 날 (2026년 지방선거 포함) |

### 알려진 제한

- **명절은 2024~2030년만 표시됩니다.** `client.js`의 `LUNAR_ANCHORS`에 해마다 `[설날, 추석, 부처님 오신 날]`의 양력 날짜(`MM-DD`)를 한 줄 추가하면 확장됩니다. 과학기술정보통신부 관보의 부력(陰曆) 대조표에서 확인하고 기재하세요. 그 밖의 연도에도 양력 공휴일과 대체공휴일은 계속 표시됩니다.
- **임시공휴일**은 수시 지정이라 계산으로 알 수 없습니다. 필요하면 `FIXED_HOLIDAYS`에 직접 추가하세요.
- 2026년부터의 노동절·제헌절 공휴일 적용은 2차 자료로 확인한 값입니다. 실제 적용과 다르면 `FIXED_HOLIDAYS`의 `y >= 2026` 줄을 조정하면 됩니다.

## 구조

```
package.json        dsh.bundle.patch 선언 + 웹 클라이언트 주입 설정
cordis.patch.yml    Loader에 플러그인 행 삽입
plugin/host.js      Host 반쪽 (hideOnMobile 설정 선언, 동작 없음)
client.js           Client 반쪽 (모든 렌더링 · 저장 · 공휴일 계산 · 모바일 숨김)
locale/*.json       플러그인 관리자용 제목 · 설명 · 설정 항목 문구
icon.svg            플러그인 아이콘
docs/screenshot.png README 상단 스크린샷 (다크 테마)
```

동작은 전부 브라우저에서 DOM으로 처리합니다. Host에는 파일을 쓰지 않고, 네트워크 요청도 없습니다. Host가 선언하는 것은 `Config` 하나뿐이고, 그 값 역시 브라우저가 DOM으로 판단하는 데만 쓰입니다.

## 개발

워크스페이스 폴더를 그대로 설치한 경우(`link:` 설치) 코드를 고른 뒤 **재설치 + 새로고침**하면 반영됩니다.

```
npm install          # 설정 스키마용 @deepseek-ai/schemastery (link 설치라면 한 번 필요)
npm run check        # node --check client.js && node --check plugin/host.js
```
